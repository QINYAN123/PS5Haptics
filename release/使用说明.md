# PS5 手柄 · 声音触感

作者：轻言black · 哔哩哔哩 https://space.bilibili.com/65980286 · GitHub https://github.com/QINYAN123/PS5Haptics（软件左下角也能点开）

让 PC 上的 PS5 手柄（DualSense）在**玩游戏、看电影、听音乐**时都有完整的触感：

- **三个使用场景**（窗口顶部三选一，每个场景各存一套设置）：
  - **游戏**：打击、碰撞、爆炸变成握把触感；支持 PS5 手柄的游戏保留原生自适应扳机和音圈；鸣潮、影之刃零有专属适配。
  - **影院**：低频隆隆、爆炸厚重；扬声器播放原声。不需要虚拟手柄。
  - **音乐**：握把和扳机跟着鼓点律动。不支持手柄震动的游戏也可以用它「加氛围」。
- **手柄扬声器**：全部游戏声（完整播放并覆盖游戏自己的手柄扬声器声音，可选 原味 / 低音饱满 / 人声清晰 三种音色）或 特殊事件（不接管游戏自己的手柄扬声器声音）。
  - 自带手柄扬声器音效的游戏（如影之刃零）：在「原生透传」下直接播放**游戏自己发给手柄扬声器的声音**（格挡、完美闪避等音效由游戏决定），和 PS5 上一样；选「全部游戏声」时只放完整的游戏声音。
  - 其他游戏 / 电影 / 音乐里「特殊事件」自动按全部游戏声播放。
- **《鸣潮》自适应扳机**：读屏识别技能状态，大招就绪时 R2 变成「咔哒」武器扳机，声骸就绪时 L2 有阻力；扳机按过咔哒点游戏才收到按键。
- **《影之刃零》事件特调**（可选）：需要先装社区的 UE4SS（[Nexus 下载页](https://www.nexusmods.com/phantombladezero/mods/5)），再在「游戏适配 → 影之刃零 → 齿轮」里点「一键安装事件 mod」。
- 开着杜比全景声 / 空间音效也能用：自动按进程截取游戏、播放器、浏览器或音乐软件的声音。

> 本软件只读取屏幕画面、游戏声音，并创建虚拟手柄；**不注入、不修改任何游戏文件**。即便如此，第三方工具的使用风险仍需自行承担，作者不对账号安全作任何保证。

## 系统要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 2004（20H1）或更新的 64 位 Windows 10 / 11 |
| 手柄 | PS5 DualSense（普通版或 Edge），用 **USB 线**或 **DS5Dongle 系接收器（测试版）**连接（触感、扬声器走手柄的 USB 声卡；电脑自带蓝牙直连不支持） |
| 驱动 | usbip-win2、HidHide、ViGEmBus（发布包自带，首次打开自动提示安装） |
| 管理员权限 | 只在安装驱动、关闭英特尔 USB 音频时需要（会弹出 UAC 确认） |
| 其他 | 运行期间请不要同时打开飞智空间站 / XHaptics、DS4Windows、DSX 等同样接管手柄的软件 |

## 安装

1. 解压整个压缩包到任意文件夹（路径可以有中文）。**不要只拿出 exe**，`依赖.exe` 和 `依赖安装包` 文件夹要和软件放在一起。
2. 双击 `依赖.exe`（压缩包最外层和 `PS5声音触感` 文件夹里都有一份），允许管理员权限，等它装完缺少的驱动。没有「依赖安装包」文件夹时，它会从驱动的官方 GitHub 下载同一版本并校验后再安装。装完建议**重启一次电脑**。
   （也可以直接打开软件：它会自动检测，缺什么就弹窗帮你装。）
3. 用 USB 线连接 PS5 手柄，或者用接收器连接（见下面「无线接收器」）。
4. 打开 `PS5声音触感\PS5Haptics.exe`，点右上角「启动」，**然后再启动游戏**（游戏已开着的话请重启游戏，让它认到虚拟手柄）。

## 无线接收器（DS5Dongle，测试版）

这项兼容还没有在接收器实机上验证，欢迎反馈结果。按设计支持基于 [awalol/DS5Dongle](https://github.com/awalol/DS5Dongle) 的接收器：Pico 2 W、BL616（M61）、DS5 Bridge 等。接收器和手柄配好对后，软件把它当成有线手柄使用。

- 接收器要用 DualSense 或 DualSense Edge 身份。DS5 Bridge 的 DS4、Xbox 身份本软件不支持。
- 关掉固件或配套软件里的「声音转触感」，不然会和本软件重复。运行时也不要开 DS5 Bridge 配套软件。
- Pico W（RP2040）固件没有扬声器，只有触感。
- 手柄休眠或断开后接收器的 USB 设备会消失，软件会停止，重新连上后再点「启动」。

## 只认 Xbox 手柄的游戏

有些游戏（如鬼武者）不认 PS5 手柄。在游戏场景的「连接方式」里选「虚拟 Xbox」，再启动游戏，并建议关掉这款游戏的 Steam 输入（游戏属性 > 控制器）。这个模式下音圈触感和扳机震动都正常工作（由声音和游戏震动生成），但没有游戏专门设计的扳机阻力和音圈波形，因为游戏发给 Xbox 手柄的只有两路马达震动。

## 操作触感、手柄输入

- **连接方式**（「设置」页最上面）：原生透传 / 接管 / 虚拟 Xbox / 普通。用虚拟 Xbox 时一定要关掉这个游戏的 Steam 输入（Steam 库里右键游戏 → 属性 → 控制器 → 禁用 Steam 输入）。
- **扳机手感**（「设置」页）：左右扳机各选一个预设（声音震动、轻阻力、重阻力、后段阻力、渐重、枪械扳机、连发震动），再用起点、强度、断开点、频率滑块微调。默认是声音震动。原生透传下游戏自己用扳机时，按扳机来源的设置，游戏优先。
- **我的游戏**（「游戏适配」页）：点「添加游戏」选游戏的 exe，可以上传封面或用 Steam 封面。打开「使用这个游戏的专属设置」后，这个游戏有自己的一整套设置（连接方式、触感、扳机手感、扬声器等），游戏在前台时自动换上，切走时回到通用设置。连接方式和声音来源在点「启动」时决定，要用游戏自己的连接方式，先打开游戏再点「启动」。
- **自检与反馈**（「系统」页）：「开始自检」检查驱动、手柄、手柄声卡、HidHide、英特尔 USB 音频和最近的报错，运行中还会记下最近 60 秒每一路震动的来源（声音、游戏原生波形、游戏马达、事件特调）。「反馈到 GitHub」生成报告、复制到剪贴板并打开 GitHub 反馈页，粘贴后提交。报告保存在 diagnostics 文件夹，去掉了用户名和电脑名，不会自动上传。软件出错停止时会自动保存一份报告。
- **握把风格「细腻」**（「设置」页，默认仍是「均衡」）：用 6 个载波细分声音，提高中高频细节占比，不同声音的手感差异更大，同时带上声音本身的低频。可以在运行中和「均衡」来回切换对比。
- **纯人声时不震**（「设置」页，游戏场景默认开，影院和音乐默认关）：只有台词、旁白时压掉声音触感，同时有打击、爆炸就不压，不影响游戏原生震动。用小模型 Silero 在本机判断，声音不会上传。开口的第一下、背景音很响时的台词还是可能会震。
- **预设**（「设置」页游戏场景最上面）：声感 = 不用游戏的震动和扳机，只用本软件由声音生成的，扬声器放全部游戏声（要用虚拟手柄，普通模式拦不住游戏）；全感 = 游戏效果和声音触感一起（默认）；自定义 = 你自己的组合，手动调过后自动记住，点它就能恢复。
- **握把、扳机来源**（「设置」页 → 高级设置 → 连接方式）：叠加（游戏和本软件一起）、替换（只用本软件的）、纯用游戏（关掉本软件的）。扳机同一时间只能跑一个效果，所以叠加时，游戏在用的那一侧归游戏，另一侧归本软件。扳机默认是自动：游戏发过扳机效果就交给游戏并记住，这个判断只在原生透传下有效，点「重置让位记录」可以清除。
- **左右强度**（「设置」页 → 高级设置）：左右握把、左右扳机可以分别调。扳机滑块只调本软件生成的震动，不改游戏原生效果。
- **操作触感**（各场景的设置页）：按键、扳机、摇杆、触摸板可分别打开，用握把给一个短促反馈，默认关闭。
- **输出到耳机孔**（手柄扬声器面板）：把声音送到手柄的 3.5 mm 耳机孔。
- **摇杆死区、校准陀螺仪**（游戏场景的「手柄输入」）：只对虚拟手柄生效。校准时把手柄平放约 2 秒。
- **左右握把对调、触感不随系统音量变化**：同样在「手柄输入」里。后者是实验性功能，默认关闭。
- 启动时日志会显示手柄固件信息，反馈问题时可以附上。

## 推荐设置

设置改了马上生效，不用重启；只有「连接方式」「声音来源」等少数项需要重启，界面顶部会出现提示条和「立即重启应用」按钮。

在窗口顶部选场景即可，各场景的默认设置已经调好（带绿色「推荐」标签）。需要细调时打开左边的「设置」页，不常用的选项在「高级设置」里：

| 场景 | 连接方式 | 扬声器 | 适合 |
|---|---|---|---|
| 游戏 | 原生透传 | 特殊事件（或 全部游戏声 · 原味） | 玩游戏；索尼第一方等原生适配好的游戏可把握把改成「纯用游戏」 |
| 影院 | 普通 | 全部游戏声 · 低音饱满 | 电影、剧集、视频 |
| 音乐 | 普通 | 全部游戏声 · 低音饱满 | 听歌、音游、给不支持震动的游戏加氛围 |

## 《鸣潮》支持范围

技能识别读屏幕右下角的技能按钮（OCR 读冷却数字），目前校准的条件是：

| 条件 | 支持 |
|---|---|
| 画面比例 | **16:9**（1920×1080、2560×1440、3840×2160 等）；超宽屏 / 16:10 暂不支持 |
| 显示模式 | 全屏或无边框全屏，游戏在**主显示器** |
| 操作方式 | **手柄**（战斗中右侧一列带 L2 / R2 标签的技能按钮）；键鼠界面只做了部分支持 |
| 界面缩放 | 游戏默认界面大小 |
| 画面 | 识别按画面亮度自适应，SDR、HDR 都按设计支持；目前实测环境是 HDR + RenoDX + DLSS，普通 SDR 电脑的反馈欢迎提交 |
| 游戏语言 | 任意（只读数字和按钮标签） |

识别不到时（过场、菜单、其他界面）扳机会自动放松，不会卡住。

## 常见问题

**手柄没有震动 / 震动很弱**
部分笔记本的「适用于 USB 音频的英特尔® 智音技术」会吞掉手柄的触感声道。打开软件「系统」页，点「关闭英特尔USB音频」，软件退出时会自动恢复。

**手柄扬声器没声音，或总览页提示「截不到游戏声音」**
声音来源保持「自动」即可（开着杜比全景声 / 空间音效也能截到）。如果仍然没有，请在 Windows 声音设置里关闭该输出设备的「空间音效」，并取消「允许应用程序独占控制此设备」。

**游戏里手柄失灵 / 软件崩溃后手柄插上去识别不到**
打开软件，在「系统」页点「修复手柄」（启动失败时红色提示条上也有这个按钮）：取消对游戏的隐藏、关闭残留的虚拟手柄，然后把手柄拔掉重插或重启游戏。软件每次打开也会自动检查一次。软件打不开时，双击 `一键恢复手柄可见性.cmd`。

如果原生透传提示「多个 VHCI 接口」，点红色提示条的「修复 VHCI」，允许管理员权限。工具只会停用经核对的闲置 usbip-win2 重复实例。看到只剩一个启用接口后，回到软件重新点「启动」。若多个实例正在使用，先退出相关的虚拟手柄或 USB/IP 软件并断开它们挂载的设备，再重试修复。停用的实例可在设备管理器里重新启用。

**HidHide 开了反向模式（Inverse）**
软件运行期间会临时关闭反向模式，停止后恢复。如果你还用 HidHide 隐藏了别的设备，运行期间其他程序可能看不到它们。

**界面语言**
支持中文 / English / 日本語 / 한국어：左下角「语言」点一下即可切换（软件会自动重启）。第一次打开时按 Windows 的显示语言自动选择。

**影之刃零更新后事件特调没反应**
游戏大版本更新可能让 UE4SS 暂时失效（软件会在游戏运行 3 分钟没收到事件时提示）。等 UE4SS 作者更新后重新安装即可；期间原生触感和声音触感不受影响。

**和杀毒软件**
同时安装两款杀毒软件（例如 360 和火绒）会互相冲突，容易导致电脑蓝屏，建议只保留一款。

## 更新

软件每次打开会在后台检查 GitHub 上有没有新版本（左下角「检查更新」也可以手动检查）。有新版本时，标题栏下方会出现一条绿色提示：
- **在线更新**：自动下载并安装，软件会关闭、更新、再自动打开；你的设置、日志和封面缓存都会保留。
- **GitHub 下载**：在线更新失败（网络打不开 GitHub 等）时，到 GitHub 主页的 Releases 手动下载新版本，解压覆盖即可。
- **忽略此版本**：这个版本不再提示，下一个版本还会提示。

## 卸载

1. 关闭本软件。
2. 删除软件文件夹。
3. 驱动可以在「设置 → 应用」里卸载 usbip-win2、HidHide、ViGEmBus（其他软件也可能用到它们，例如 DS4Windows）。
