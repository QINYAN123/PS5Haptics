# 2.3.7 扬声器处理修订

针对游戏中金属声、高频破音的反馈调整输出链；尚未确认白色手柄的物理破音原因，也没有做声学校准。

- 特殊事件遵守音量滑块，取消至少 80% 音量及额外 1.5 倍增强。
- 收敛 clang/whoosh 高频增强与虚拟低音。RawSpeaker 补偿增益上限由 4 倍降为 2 倍，去除额外 1.5 倍及 tanh 波形饱和。
- 原生音效保留独立来源，补偿增益在块内渐变，不再提前硬削波。
- 真手柄内部扬声器音量由 0x64 调整为 0x48，与此前直接试听一致；硬件前置增益未改变。
- 输出统一经过二阶 180 Hz 高通、二阶 6.5 kHz 低通及 5 ms 前瞻限幅（峰值 0.70，80 ms 释放）。衰减在前瞻窗口内平滑展开，不以 tanh 制造额外谐波。
- 耳机孔不使用小扬声器的高低通，限幅峰值为 0.95。左右握把 PCM 不经过这条链。
- 空块排空滤波器与前瞻缓存；输出路由改变时重建状态；NaN/Inf 替换为静音，异常幅值受限，避免污染后续状态。
- 诊断区分输出欠载、限幅采样数和异常采样数，便于继续区分失真与传输断续。

这些截止频率和峰值是保守工程默认值，不是 Sony 参数，也不是针对 BDM-040 实测获得的频响补偿。扬声器会更克制，原味模式也经过保护。扬声器增加固定 5 ms 延迟，握把和扳机不增加延迟。

## 验证

`python -m unittest test_speaker_safety test_dsp -v`、`python test_compat.py`、`python test_event_fx.py`。

另外以两段各 60 秒原生扬声器录音离线处理，输出均有限、无越界；这两段未触发限幅，不能证明已经重现或解决用户实际破音。验证涵盖过载、静音、非有限数、分块连续性、频段衰减、耳机延迟及握把通道保持。

仍需白色手柄在同一游戏事件中试听。滤波/限幅不能修复物理松动，也不能恢复音源中已经失真的声音；输出欠载计数增长时需排查调度和音频设备链路。

## 回退

正常退出软件后，用上一版本的程序包还原程序和依赖；保留自己的配置、日志和事件设置。
